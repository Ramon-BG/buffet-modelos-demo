# Demonstração de sites para buffet

Quatro modelos ilustrativos para avaliação visual e comercial. Marca, localização e conteúdo fictícios. Contato simulado, sem envio ou armazenamento de pedidos.

Fotografias de referência com licença CC0; fontes e autoria nas páginas de créditos. Agenda, pagamentos e reservas reais não estão implementados. A proposta descreve os limites e as possibilidades de contratação futura.
